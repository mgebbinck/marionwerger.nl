# marionwerger.nl

Statische website van **Marion Werger Coaching & Yoga**, klaar om te hosten op GitHub Pages.

## Inhoud

| Bestand | Pagina |
|---|---|
| `index.html` | Home |
| `wat-is-ademwerk.html` | Ademwerk – Wat is ademwerk? |
| `ademcoaching.html` | Ademwerk – Ademcoaching, individuele sessie |
| `ademcirkels.html` | Ademwerk – Ademcirkels |
| `yogastijlen.html` | Yoga – Wat is Yoga / Yogastijlen |
| `individuele-yoga.html` | Yoga – Individuele Yoga |
| `groepslessen.html` | Yoga – Groepslessen |
| `bedrijfsyoga.html` | Yoga – Bedrijfsyoga |
| `coaching.html` | Coaching – Coaching Stressreductie |
| `herstel-bij-burn-out.html` | Coaching – Herstel bij Burn-out |

| `mountainbikereis-nepal.html` | Reizen – Mountainbikereis Nepal |

| `algemene-voorwaarden.html` | Algemene voorwaarden |
| `privacyverklaring.html` | Privacyverklaring |

Opmaak staat in `assets/css/`, alle foto's in `assets/img/`. Thema-scripts, fonts,
faviconbestanden en reisdocumenten staan lokaal in `assets/js/`, `assets/fonts/`,
`assets/img/` en `assets/docs/`.
De site is statisch: geen build-stap, geen framework, geen database of WordPress-assets.

## Publiceren op GitHub Pages

GitHub Pages publiceert deze statische site automatisch vanaf de `main`-branch
van de repository. De GitHub Pages-kopie is publiek toegankelijk op
<https://mgebbinck.github.io/marionwerger.nl/>.

Het domein `marionwerger.nl` is niet aan deze GitHub Pages-site gekoppeld; het
blijft de afzonderlijke WordPress-site. De GitHub Pages-publicatie verandert
die live website niet.

## Nog aan te vullen

- Het contact- en proeflesformulier opent het e-mailprogramma van de bezoeker. Wil je
  een echt verzendend formulier, koppel dan een dienst als Formspree of Netlify Forms
  (GitHub Pages kan zelf geen formulieren verwerken).
- Actuele lesroosters, data en prijzen: controleer voor livegang of alles nog klopt.
